## Overview

- Gather data to make applications more efficient
- Agent-based—low impact
- Analyses CPU/memory intensive functions
- Improve performance and reduce costs
- 30 day retention of profiles
- Profiles exportable
- Available for [Compute Engine](Compute%20Engine.md), [App Engine](App%20Engine.md), [Kubernetes Engine](Kubernetes%20Engine%20(GKE).md) and [Dataproc](Dataproc.md)
- External apps available via agent
